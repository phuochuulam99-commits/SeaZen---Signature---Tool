Dán vào email

  1. Outlook mới / Outlook web: Settings (bánh răng) → Account → Signatures → New signature → đặt tên → dán (Ctrl+V).
  2. Quan trọng: ngay sau khi dán, bấm vào nút (Ctrl) hiện ở cuối chữ ký → chọn Keep source formatting. Nếu bỏ qua bước này, chữ sẽ bị chuyển sang màu đen trên nền tối.
  3. Bấm Save, rồi chọn chữ ký này làm mặc định cho thư mới và thư trả lời.
  4. Outlook bản cũ trên máy tính: File → Options → Mail → Signatures → New → đặt tên → dán (Ctrl+V) → OK. Nếu chữ bị đen, bấm (Ctrl) → Keep Source Formatting.
