Dán vào Outlook

  1. Outlook mới / Outlook web: Settings (bánh răng) → Account → Signatures → New signature → đặt tên → dán (Ctrl+V).
  2. Bấm Save, rồi chọn chữ ký này làm mặc định cho thư mới và thư trả lời.
  3. Outlook bản cũ trên máy tính: File → Options → Mail → Signatures → New → đặt tên → dán (Ctrl+V) → OK.
